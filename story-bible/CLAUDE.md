# CLAUDE.md — story-bible/

Canon for the world. Not prose: stories go in `../stories/`. **Agents never change this folder.** Canon changes are proposed to the author and applied only once he approves (`../publishing-house/WORKFLOW.md`).

Migrated on 2026-10-17 from the world plan built with the author (archived at `../reference/world-plan-v1.md`). That migration has **not yet been audited** for gaps or contradictions; ticket T-001 does that.

## Reading order for a new task
- **Writing or editing a story?** Start with `../writing-guide/`, then come back here.
- **What is this project?** → `00-story-identity.md`
- **Where and when?** → `01-world.md`, then `timeline.md` (chronology *and* telling order)
- **Why does anything happen?** → `chain-of-intentions.md`, the causal spine
- **What happens in an era?** → `eras/`
- **A kind of being?** → `roster.md` for the archetypes, `species/` for the lore
- **Ages, births, conjuring?** → `ages-and-lifespans.md`, `reproduction.md`
- **Magic?** → `magic/` (forms to fill, mostly blank by design; the guidelines live in `../writing-guide/magic-system/`)
- **Already seeded or spoiled?** → `foreshadowing-map.md`, `plot-twist-inventory.md`
- **Not sure it's settled?** → `open-questions.md`. Anything listed there is not canon.

## Status flags
Files with open development needs carry a `status:` line in their frontmatter. `draft` means migrated but unaudited; `open` means a decision is still needed.
