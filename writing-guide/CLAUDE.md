# CLAUDE.md — writing-guide/

Read before outlining and before drafting. Carried over from *Vector Anthologies* where the author's standards were first worked out, and adapted for this genre.

**Drafting prose:**
- `style-guide.md` — length, the A-to-B requirement, dialogue, the horror hum. The **narrator is open** (being researched) and the **tone ratio is provisional**; both are marked in the file.
- `story-laws.md` — hard constraints. **Law 1, the age rule, can never be broken.**
- `gaze-guide.md` — the crossed gazes and the women-lead / men-support flip.
- `fiction-style-profile.md` — the reader-preference research behind the prose defaults, unchanged from Vector because the author's taste is shared across both projects.

**Outlining:**
- `outline-checklist.md` — sequencing events before any scene is written.
- `character-journey-worksheet.md` — one per POV or major character, before outlining.

**Evaluating a finished draft:**
- `eval-checklist.md` — run once per draft; record the result in the story's `eval_status`.

**Magic:**
- `magic-system/` — two guidelines (Seven Domains, Magic Management). Tools, not canon. See its `CLAUDE.md`.

Changing any of these files is a deliberate decision by the author, not an incidental edit while drafting.
